# Computer Vision + Robotics: my learning journey

I'm learning to build machines that see and act: cameras that understand the world, and robots that move because of what they see. This repo is my public notebook. Everything here is something I built, broke, and fixed myself.

## Why this

I chose computers because I like building things and because I want a good career. After trying other directions, I settled here because the results are visible: run the code, and an image gets labelled or a robot moves.

## Where I am now

- Level: beginner. Learning Python and OpenCV first, C++ later.
- Goal for 12 months: 3 working projects, one of them on real hardware, plus first paid Python/automation work.
- Goal for 24 months: a junior role in machine vision, perception, or robotics software.

## What I'm learning

| Area | Tools |

| Programming | Python, then C++ |
| AI agents | LLM APIs or local models, tool calling |
| Image processing | OpenCV |
| Deep learning | PyTorch, YOLO |

| Math, as needed | Linear algebra, probability |

## How I earn while I learn

Robotics takes time, so I'm also doing small paid work that builds the same skills:

- Python automation and Telegram bots for small businesses.
- Simple AI assistants (tool-using agents) for support and documents.
- Vision-flavoured gigs when I can find them: counting, plate reading, defect checks.

Rough split of my time: 60% paid work, 40% CV and robotics projects. Paid work is shown here only with the client's permission.
